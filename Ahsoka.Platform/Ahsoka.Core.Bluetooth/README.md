# OpenPV - Ahsoka.Core.Bluetooth

Ahsoka.Core.Bluetooth contains the Ahsoka Service for interacting 
with a Classic Bluetooth Stack.   Dpending on the platform this 
stack may use native stacks or BlueZ on Linux.
