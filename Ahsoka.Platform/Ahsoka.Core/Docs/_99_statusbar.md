# Status Bar Tools {#StatusBar}

The status bar shows information about your connected target, the last running process as well as giving you access to various development actions.

\image{inline} html /Images/StatusBar.png "Status Bar"

**StatusArea** - The far left side of the status bar shows the connection state (blue or grey) as well as the type of display connected currently.   When a background process is running this area shows the last message sent to the console.

**Active Connection** - The far right side shows the selected connection (from the Displays List).  You can selecte between connections using this drop down.

**Reboot Display** - This button will send a reboot command to the connnected display
 
**Stop Customer Application** - If the customer application is running, this will stop it and return to the visual installer.  This is required to send an update to the target.
 
**Help** - Selecting this button will open the API and Tools Help in your internet browser.
