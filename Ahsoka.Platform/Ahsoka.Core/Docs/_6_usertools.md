# User Tools {#UserTools}

## Projects{#Projects}

The Projects Manager allows you to create and participate in OpenPV Teams.  Teams allow you to share device keys, devices, applications and other multi-user features.   A team should be created for each set of devices / products you plan to build with the OpenPV Toolkit as it simplifies the management of not only the devices but also the applications and their related data.

**Members** - From this screen you can add and remove a team as well as add and remove team members.   The members much already have an OpenPV Login to become a member.  Currently, only the team "creator" can own the team as well add / remove team members however future releases will extend this functionality to allow multiple owners and other roles.

**Containers** - This shows a list of the Containers which hold Spark Applications which have been uploaded.  From here you can promote / demote and application from Develop -> Beta -> Release.   This allows you to gradually release applications to your customers as they are tested.

**Spark Devices** - This is a list of devices that are part of your teams Development, Beta or Release Device Groups.  From here you can promote and demote displays allowing them to be used for development or limited to released software builds in Spark.

**Keys** - As devices are secured in the Displays Tool, any keys will be shown here.  This allows you to share SSH keys with other team members in scenarios where development displays must be passed from team member to team member.

## Account {#Account}

This tool shows information about your Spark Account (required to use OpenPV)

**Change Info** - This tab allows you to update your name or other info and update it in spark.   In addition you can log out of the tool from this screen.

**Change Password** - This tab allows you to update your password. Note that you must enter your current password again in order to make this change..

**About OpenPV** - This tab shows information about the Open Source Projects used to build OpenPV and its related SDK's and Tools
